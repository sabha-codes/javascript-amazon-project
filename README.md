# Amazon Clone – JavaScript Project

This project was built by following along with the JavaScript course by Simon Bao from SuperSimpleDev.

I wrote the code while learning and practising JavaScript concepts throughout the course. This project helped me understand how these concepts work together in a practical e-commerce website.

## Technologies Used

* HTML
* CSS
* JavaScript
* Jasmine (for testing)

## What I Learned

While building this project, I learned and practised:

* Strings, variables, Booleans, and conditional statements
* Functions and objects
* DOM manipulation
* Arrays and loops
* Advanced functions and callbacks
* JavaScript modules and external libraries
* Object-oriented programming, classes, and inheritance
* Promises, async/await, and Fetch API

## Project Pages

* `amazon.html` – Main shopping page
* `checkout.html` – Checkout page
* `orders.html` – Orders page
* `tracking.html` – Order tracking page

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `amazon.html` in your browser or use the Live Server extension.

Some functionality may require a local server or the backend service used in the course.
